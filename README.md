# Kavin M | Personal Portfolio Website

A responsive personal portfolio website built with **HTML, CSS and JavaScript**. It introduces me as a web developer and presents my education, skills, projects and contact details in a clean black and white design.

🔗 **Live Site:**  https://kavinmanikandan22.github.io/My-Portfolio/

## Sections

| Section | What it shows |
|---------|---------------|
| **Home** | Introduction with my name, role and a circular profile photo |
| **About Me** | Education summary with switchable tabs: Skills, Experience, Education and Achievements |
| **Skills** | Six skill cards with icons and progress bars: React, HTML5, CSS3, JavaScript, Tailwind CSS, Git & GitHub |
| **Projects** | Four numbered project cards with images, descriptions, tech tags and links |
| **Contact** | Working contact form, contact details, LinkedIn, GitHub and a CV download button |

## Features

- Fully responsive layout for desktop, tablet and mobile
- Fixed navigation bar with smooth scrolling and a mobile hamburger menu (pure CSS)
- Tabbed About section built with JavaScript
- Skill cards with progress bars and hover effects
- Contact form that delivers messages to my email using [FormSubmit](https://formsubmit.co)
- Downloadable CV

## Run Locally

1. Clone the repository
   ```bash
   git clone https://github.com/kavinmanikandan22/YOUR-REPO-NAME.git
   ```
2. Open the folder in VS Code
3. Right-click `index.html` and choose **Open with Live Server**

> The contact form only works when the site is opened through a web address (Live Server or GitHub Pages), not by opening the HTML file directly. The first submission also sends an activation email to the receiving inbox, which must be confirmed once.

## Deployment

The site is hosted with **GitHub Pages**:
`Settings` → `Pages` → choose the `main` branch → `Save`.
